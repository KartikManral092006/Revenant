Glossary

Ghost Memory
The recording step. We run the original package on many generated inputs and write down what it does.
Evidence
One recorded input and the original's response. Everything later is built from it. It shows how a package behaved on tested inputs; it is not proof for inputs that were not tested.
Behavior group (behavior class)
A set of similar inputs with the same kind of outcome, used to summarize the evidence.
Intentional difference
A planned, documented place where the rebuild differs from the original, usually a security fix. Left out of the match score and listed separately.
Prototype pollution
A bug where crafted input changes the shared template that all objects inherit from.
