Step 4 of 5 · Resurrection · happens in Kiro, not in this page

The rebuild: not started

No rebuild exists for string yet. Rebuilding is careful work done by a person in Kiro, so Revenant only rebuilds a few packages. So far that is lodash.set and lodash.pick.

To make one: download the spec bundle above, open it in Kiro, and build from it.
